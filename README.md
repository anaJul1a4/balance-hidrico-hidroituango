# Balance hídrico de largo plazo · Río Cauca hasta Hidroituango

Informe interactivo del Trabajo 1 de Hidroclimatología (Universidad Nacional de Colombia): balance hídrico 1981–2010 de la
cuenca aportante a la presa de Hidroituango (35 992 km²), con estaciones IDEAM, el DEM Copernicus GLO-30 y los productos
CHIRPS, ERA5-Land y ERA5.
